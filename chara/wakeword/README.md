# Обучение wakeword-модели

## Запуск

### 1. Создать среду wakeword

В терминале из корня репозитория:

```sh
conda create -n wakeword --clone brainbox -y
conda activate wakeword
cd chara/wakeword
```

Среда копируется вместе с зависимостями. Команду `cd` выполняйте из корня репозитория.

### 2. Указать wakeword

В [learn-settings.json](learn-settings.json) замените значение `generation.target_variants` на своё слово или фразу:

```json
"target_variants": ["computer"]
```

Сейчас поддерживается английский язык. Остальные настройки можно оставить как есть.

### 3. Запустить BrainBox

В другом терминале из корня репозитория активируйте среду `brainbox` и запустите сервер:

```sh
conda activate brainbox
python -m brainbox.run --data-folder ./brainbox-data
```

Вместо `./brainbox-data` укажите свой каталог данных BrainBox. Оставьте сервер запущенным.

### 4. Подготовить ресурсы и запустить обучение

В терминале со средой `wakeword`, из `chara/wakeword`:

```sh
make setup
make check
make run OUTPUT=../../temp/wakeword/my-word-001
```

При первой подготовке скачиваются модели и данные — потребуется больше 25 ГБ свободного места. Для следующего запуска с другим словом укажите новый каталог `OUTPUT`.

### 5. Забрать результат

В `temp/wakeword/my-word-001/training/` от корня репозитория:

- `wakeword.onnx` — готовая модель;
- `report_ru.html` — отчёт о качестве обучения.

## Как работает пайплайн

1. **Генерация речи.** ParlerTTS через BrainBox озвучивает wakeword разными голосами и похожие фразы без него. Vosk проверяет и вырезает целевое слово из позитивных записей.
2. **Подготовка данных.** К аудио добавляются фоновые звуки и эффекты помещения. Записи преобразуются в признаки и разделяются на обучающую и проверочную выборки.
3. **Обучение.** Классификатор учится отличать wakeword от похожих фраз и фоновых звуков. Генерация речи выполняется в BrainBox, обработка данных и обучение — в среде `wakeword`.
4. **Результат.** Пайплайн выбирает и объединяет лучшие сохранённые состояния модели, экспортирует ONNX, проверяет её и создаёт отчёт.

Данные сохраняются в `OUTPUT/generation/`, модель и отчёты — в `OUTPUT/training/`.
